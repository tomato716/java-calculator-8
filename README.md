# java-calculator-precourse

## 기능 구현 목록

- [ ] 덧셈할 문자열 입력
    - [ ] `""` 빈값이 입력 될 경우 `결과 : 0` 반환
    - [ ] `예외 발생` : 입력값이 숫자가 아닌 경우
    - [ ] `예외 발생` : 음수값이 입력될 경우
- [ ] 숫자 구분자에 따라 숫자 분리
    - [ ] `예외 발생` : 숫자 구분자가 `,` , `:`가 아닌 경우
- [ ] 커스텀 구분자가 있을 경우 구분자에 포함
    - [ ] 커스텀 구분자는 `//`와 `\n`사이의 문자로 구분된다.
    - [ ] 커스텀 구분자는 문자열 맨 앞에 와야한다.
- [ ] 구분자로 나뉜 숫자들을 덧셈
